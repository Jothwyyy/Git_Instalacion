# Git_Instalacion

Repositorio de práctica para documentar la instalación, configuración y uso básico de Git.

## Objetivo

Practicar un flujo básico de control de versiones utilizando Git, Visual Studio Code y WSL.

## Contenido del repositorio

- Configuración inicial de Git.
- Creación de estructura base del proyecto.
- Uso de commits.
- Uso de branches.
- Uso de merge.
- Revisión del historial del repositorio.

## Workflow utilizado

El flujo de trabajo consiste en trabajar desde una rama principal llamada `main` y crear ramas secundarias para cambios específicos, como documentación o nuevas funcionalidades.
